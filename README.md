# Алгоритм пошуку оберненої матриці та його паралельна реалізація на C#

Курсова робота. Автор: Адаменко Арсен, ІП-35.

## Зміст

Реалізовано два варіанти алгоритму Гаусса-Жордана для обернення квадратної невиродженої матриці:

- **SequentialSolver** — однопотокова версія;
- **ParallelSolver** — паралельна версія: персистентний пул потоків (System.Threading.Thread) з полегшеною бар'єрною синхронізацією `PhaseBarrier` (Interlocked + пара ManualResetEventSlim). Паралельно виконуються всі етапи: ініціалізація `[A | I]`, пошук головного елемента, нормалізація опорного рядка, виключення та копіювання результату.

Обидві реалізації використовують вибір головного елемента **без перестановки рядків**: рядок з найбільшим за модулем елементом стовпця додається до опорного рядка (елементарне перетворення), тому порядок рядків не змінюється і права половина в кінці одразу дорівнює `A^(-1)`.

## Збірка та запуск

Потрібен .NET 8 SDK.

```bash
dotnet build -c Release
dotnet run -c Release
```

Після запуску відкриється інтерактивне меню:

1. Запустити алгоритм на існуючому датасеті.
2. Згенерувати нову тестову матрицю.
3. Запустити тести коректності (14 тестів).
4. Запустити бенчмарк (виводить таблиці + зберігає `benchmark_results.csv`).
5. Згенерувати стандартний набір датасетів (small=1000, medium=1500, large=2000, xlarge=2500).
0. Вийти.

## Алгоритм коротко

Гаусса-Жордана зводить розширену матрицю `[A | I]` до вигляду `[I | A^(-1)]` за `N` ітерацій. На кожній ітерації `k`:

1. Знайти рядок `r >= k` з max `|a[r,k]|`; якщо `r != k` — додати рядок `r` до рядка `k` зі знаком `s = sign(a[k,k]*a[r,k])` (без перестановки рядків).
2. Поділити опорний рядок на `pivot`.
3. Для всіх інших рядків `i ≠ k` виконати `row[i] -= row[i,k] * row[k]`.

Паралельна версія: потік `t` володіє смугою рядків `[t*rowChunk, (t+1)*rowChunk)` та смугою стовпців `[t*colChunk, (t+1)*colChunk)`.
Ітерація = 2 фази між бар'єрами: (а) редукція локальних максимумів + підсилення/нормалізація своєї смуги стовпців опорного рядка;
(б) виключення у своїх рядках, злите з пошуком локального максимуму для стовпця `k+1`.

Загальна асимптотична складність — `O(N³)`.
