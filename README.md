# Алгоритм пошуку оберненої матриці та його паралельна реалізація на C#

Курсова робота. Автор: Адаменко Арсен, ІП-35.

## Зміст

Реалізовано два варіанти алгоритму Гаусса-Жордана для обернення квадратної невиродженої матриці:

- **SequentialSolver** — однопотокова версія;
- **ParallelSolver** — паралельна версія на базі Task Parallel Library (Parallel.For), що розпаралелює етап виключення (elimination).

Обидві реалізації використовують частковий вибір головного елемента (partial pivoting) для чисельної стабільності.

## Збірка та запуск

Потрібен .NET 8 SDK.

```bash
dotnet build -c Release
dotnet run -c Release
```

Після запуску відкриється інтерактивне меню:

1. Запустити алгоритм на існуючому датасеті.
2. Згенерувати нову тестову матрицю.
3. Запустити тести коректності (10 тестів).
4. Запустити бенчмарк (виводить таблиці + зберігає `benchmark_results.csv`).
5. Згенерувати стандартний набір датасетів (small=300, medium=600, large=900, xlarge=1200).
6. Вийти.

## Алгоритм коротко

Гаусса-Жордана зводить розширену матрицю `[A | I]` до вигляду `[I | A^(-1)]` за `N` ітерацій. На кожній ітерації `k`:

1. Знайти рядок з max `|a[r,k]|`, переставити з `k`-м (partial pivoting).
2. Поділити опорний рядок на `pivot`.
3. Для всіх інших рядків `i ≠ k` виконати `row[i] -= row[i,k] * row[k]`.

Етап (3) — це `(N-1) × 2N` незалежних операцій, які `Parallel.For` розкидає між робочими потоками. Етапи (1)-(2) залишаються послідовними: їхня частка у загальному обсязі — `O(N)` проти `O(N²)`, тому накладні витрати на паралельну обробку перевершили б виграш.

Загальна асимптотична складність — `O(N³)`, що дає чималий простір для розпаралелювання.
